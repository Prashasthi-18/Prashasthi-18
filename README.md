## 👩‍💻 About me

I'm **Boin Prashasthi**, a **B.Tech CSE (Cyber Security)** student at **VNR VJIET** and an aspiring **AI Engineer**. I build applications on top of LLMs that are meant to be used, not just demoed: multi-agent pipelines, RAG assistants, guardrailed chatbots and AI tools that automate software testing.

- 🤖 Building **agentic AI systems** where specialised agents plan, act and review each other's work
- 📚 Shipping **RAG** apps that let people chat with videos, documents and enterprise knowledge
- 🛡️ Interested in **safe, reliable AI**: guardrails, human-in-the-loop design, evaluation and LLMOps
- 🧪 Using AI for **QA**: generating Playwright tests from requirements and API tests from OpenAPI specs
- 🔐 Cyber security background, with a **CTF win** and 7+ CTF competitions
- 📊 Product-minded: I write **PRDs and product teardowns**, and I like building user-centric AI products
